# GameKritik — Android

Нативный проект Kotlin / Jetpack Compose по макету Figma. Версия 1.5: компактный каталог известных игровых серий с обложками, галереями, личными отзывами и материалами Steam.

## Запуск

1. Откройте в Android Studio **всю папку GameKritik**, а не вложенную `supabase`.
2. Используйте Gradle JDK 21 и Android SDK 36. Дождитесь Gradle Sync.
3. Выберите `app` и рабочее устройство, затем нажмите ▶.
4. На этом компьютере сборка и UI-тесты проверены на эмуляторе **Pixel 8**.

`local.properties` создаётся Android Studio локально и не включён в репозиторий.

## База данных

Подключён Supabase `bnceqynsvjcdiflbpilh`. В приложении используется только публичный publishable key.

**7 октября 2026 изменения применены в облаке:**

- Каталог содержит The Witcher 3: Wild Hunt, Elden Ring, Baldur’s Gate 3, Cyberpunk 2077.
- Описания, даты, разработчики, платформы и демонстрационные оценки сохранены в `public.games`.
- Пользователь регистрируется по никнейму, email и паролю. Подтверждение почты отключено по выбору владельца для учебной версии.
- Каждый новый аккаунт сохраняется в `auth.users`; триггер сразу создаёт профиль в `public.users` и связывает его через `auth_id`.
- Ранее созданный аккаунт также перенесён в `public.users`, ожидание подтверждения почты для него снято.
- Настоящие пароли обрабатывает только Supabase Auth. В старом столбце `public.users.password` хранится маркер `!supabase-auth!`.
- Вход сохраняется после перезапуска: токены шифруются AES-GCM с ключом Android Keystore. Пароль на телефоне не сохраняется.
- Пользователь читает только свой профиль и изменяет только своё избранное и отзывы. RLS остаётся включён.

Пользователи видны в Supabase → Authentication → Users и Table Editor → public.users.
Из-за исходной связи `games.developer → users.name` в `users` также есть служебные записи разработчиков и редакции без Auth-аккаунтов. Обычные пользователи имеют заполненное `auth_id`.

В базе оставлен один явно обозначенный аккаунт **Проверка регистрации** с адресом `gamekritik-check-…@example.com`: он создан автоматическим тестом через форму приложения. Это не ваш личный аккаунт.

## SQL в комплекте

- `001_android_access.sql`: каталог, защищённые функции профиля, избранного, отзывов.
- `002_catalog_examples.sql`: четыре игры из макета без изображений и выдуманных отзывов.
- `003_signup_profiles.sql`: автоматические профили при регистрации и перенос старых Auth-аккаунтов.
- `005_large_catalog.sql`: 116 игр, 340 карточек подборок руководств/подготовки к релизу, 464 скриншота и 208 трейлеров. Импорт выполнен 20.10.2026; повторный запуск не дублирует записи по URL.
- `004_existing_signup_confirmation.sql`: одноразовое применение одобренного режима без писем к прежним ожидающим аккаунтам.
- `006_franchise_catalog.sql`: Sonic, Metal Gear, классические Resident Evil, Persona и Persona 4 Revival с официальными обложками и скриншотами.
- `007_history_and_mods.sql`: приватная история просмотра (до 30 игр) и ссылки на источники модификаций для каждой игры.
- `008_remove_excess_games.sql`: сокращение каталога до 85 игр с защитой пользовательских отзывов и избранного.
- `009_my_reviews.sql`: защищённая функция для истории собственных отзывов в профиле.

Эти изменения уже выполнены в указанном проекте. Повторно запускать SQL для работы приложения не требуется.
При переносе на другой Supabase примените миграции по порядку и настройте Authentication → Sign In / Providers → Confirm email согласно нужному режиму. Для публичного выпуска потребуется отдельно настроить почту и вернуть проверку email.

## Проверки

Сборка: `gradlew.bat assembleDebug assembleDebugAndroidTest`.
UI-тесты `ScreenTest` и `FullscreenMediaTest` прошли на эмуляторе (5 проверок). `LiveCatalogTest` прошёл отдельно с облачной базой и проверил каталог из 85 игр, обложку, трейлер, гайды, моды и навигацию.
`LiveRegistrationTest` запускается только с аргументом `liveSignup=true`, поскольку создаёт реальный тестовый аккаунт в Supabase. Проверяет форму регистрации, загрузку каталога, профиль, повторный вход, сохранение сессии и избранное.

`screenshots/catalog-live.png` и `screenshots/registered-profile.png` — снимки приложения с реальными данными Supabase.

## Каталог и медиа

«Новые» показывает выпущенные проекты 2025–2026 годов; более старые игры с недавним PC-портом исключаются по году первого релиза. «Скоро выйдут» содержит Fable, Metro 2039, Tomb Raider: Legacy of Atlantis и Final Fantasy VII Revelation. Даты из Steam могут измениться; платформа и дата относятся к указанной магазинной версии.

У каждой игры есть раздел гайдов. Для выпущенных игр добавлены карточки тематических подборок Steam: прохождения, достижения, советы. Это ссылки на руководства сообщества, а не 340 написанных полных прохождений. Для будущих игр показана подготовка к релизу. Тексты чужих руководств не копируются; авторы доступны на источнике.

Обложки и скриншоты загружаются через Coil, трейлеры HLS — встроенным Media3. Для медиа требуется интернет. Видеоплеер предлагает открыть официальную страницу, если поток недоступен. Права на материалы принадлежат издателям; источники сохранены в базе.

Раздел модов ведёт на страницы руководств Steam Community, а у ряда игр — на проверенные каталоги Nexus Mods. Для будущих релизов показано честное сообщение, что модов ещё нет. Файлы модов приложение не хранит. Четыре исходные оценки из макета остаются демонстрационными до появления пользовательских отзывов. Metacritic показан отдельно, по шкале 100.

`LiveCatalogTest` проверяет доступ к настоящему каталогу, декодирование обложки, готовность HLS-потока и навигацию. Он не создаёт аккаунты. На этой Windows запуск Gradle Test Executor сталкивается с кириллицей в профиле; семь модульных тестов выполнены напрямую через JUnitCore.
`LiveSteamReviewsTest` проверяет загрузку и порядок отзывов Steam, их карточки в приложении и защищённую историю личных отзывов для уже вошедшего тестового аккаунта.

## Обложки в версии 1.2

Карточки используют широкую обложку Steam в пропорциях 460:215. Изображение показано целиком (Fit), название больше не обрезается под вертикальную миниатюру. На странице игры также показана обложка с логотипом, а скриншоты находятся в своей галерее.


## Версия 1.3 — полный экран
Скриншоты и трейлеры открываются в горизонтальном полноэкранном режиме без системных панелей. Изображение сохраняет пропорции. Нажатие на скриншот скрывает или показывает кнопки; панель видео скрывается автоматически. Крестик или системная кнопка Назад закрывает просмотр и возвращает прежнюю ориентацию. Исходные URL и содержимое медиа не изменены.

## Версия 1.4 — серии, профиль и тема
Каталог сокращён до 85 игр: инди-игры убраны, добавлены серии Sonic, Metal Gear, Resident Evil и Persona. Persona 4 Revival находится в «Скоро выйдут». История просмотренных игр сохраняется в Supabase только для вошедшего пользователя и доступна из профиля. Светлая и тёмная цветовые схемы автоматически следуют настройке телефона. Новые игры используют обложки и скриншоты официальных страниц Steam; при отсутствии трейлера раздел остаётся пустым без выдуманного видео.

## Версия 1.5 — мои отзывы и Steam
В профиле отображаются написанные пользователем отзывы с оценкой, датой и переходом к игре. Данные загружаются защищённой функцией `gk_my_reviews` по текущей сессии Supabase; чужие отзывы через неё недоступны. Раздел «Отзывы» игры отдельно загружает до пяти реальных русскоязычных отзывов Steam с высоким числом отметок «забавно» из официального API Steamworks. Для каждого есть ссылка на оригинал. Тексты Steam не записываются в базу GameKritik; при недоступности Steam показана ссылка на страницу игры.
